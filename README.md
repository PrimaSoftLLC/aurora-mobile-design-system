# Дизайн-система Aurora — токены

Источник истины: `tokens/`. Всё остальное генерируется.

## Команды

    npm test        проверки: ссылки, контраст WCAG AA, брендовая чётность
    npm run build   валидация, затем генерация Dart и Figma

Flutter-пакет:

    cd aurora_design_system && flutter test

## Как что-то поменять

Цвет, отступ, радиус — правится в `tokens/`, затем `npm run build`.
`aurora_design_system/lib/src/tokens/tokens.g.dart` руками не редактируется.

## Как добавить бренд

Скопировать `tokens/brands/aurora.json` и заменить четыре вещи: шкалы
`neutral` и `brand`, `logo` и `wordmark`. Плюс метаданные: `id`, `appName`,
`baseUrl`, `defaultLocale`, `neutralHue`, `seed`. Больше ничего: радиусы,
отступы, типографика, движение и статусные цвета едины для всех брендов,
и `npm test` это стережёт.

Шкалы перекрашиваются на месте, а не пересобираются: обе должны сохранить
ровно тот же набор ступеней, включая нестандартную `850` в `neutral`
(`parity.js` сверяет ступени с эталонным списком и падает без объяснений,
если набор не совпал). Ступень `850` существует потому, что в тёмной теме
`border.hairline` и фон панели иначе слились бы в один тон.

## Куда идёт Figma

`build/figma-variables.json` импортируется в Figma. Направление
синхронизации одностороннее: JSON → Figma. Правки цветов внутри Figma
теряются при следующей сборке — это сделано намеренно.
