# Дизайн-система Aurora — токены

Источник истины: `tokens/`. Всё остальное генерируется.

## Команды

    npm test        проверки: ссылки, контраст WCAG AA, брендовая чётность
    npm run build   валидация, затем генерация Dart и Figma

Flutter-пакет:

    cd aurora_design_system && flutter test

## Как что-то поменять

Цвет, отступ, радиус — правится в `tokens/`, затем `npm run build`.
`aurora_design_system/lib/src/tokens/tokens.g.dart` руками не редактируется.

## Как добавить бренд

Скопировать `tokens/brands/aurora.json` и заменить четыре вещи: шкалы
`neutral` и `brand`, `logo` и `wordmark`. Плюс метаданные: `id`, `appName`,
`baseUrl`, `defaultLocale`, `neutralHue`, `seed`. Больше ничего: радиусы,
отступы, типографика, движение, статусные цвета и палитра геозон едины для
всех брендов, и `npm test` это стережёт.

Шкалы подбирает дизайнер — генератора шкал нет и не планируется (§4.1 спека).
`neutralHue` и `seed` записывают замысел, а не производят цвета; `seed` при
этом обязан буквально встречаться среди ступеней собственной шкалы `brand`
(ступень не фиксирована: у Aurora это 600, у МТС 500).

`logo` и `wordmark` — имена файлов относительно `assets/brand/`
(`design-system/assets/brand/aurora.svg` и так далее). Каталога пока нет:
логотип не потребляет ни один компонент, они появятся вместе с компонентами
из §9 спека. Имена в файле бренда уже записаны, чтобы туда их и класть.

Шкалы перекрашиваются на месте, а не пересобираются: обе должны сохранить
ровно тот же набор ступеней, включая нестандартную `850` в `neutral`
(`parity.js` сверяет ступени с эталонным списком и называет недостающие и
лишние). Ступень `850` существует потому, что в тёмной теме
`border.hairline` и фон панели иначе слились бы в один тон.

## Куда идёт Figma

Сначала `npm run build` — каталог `build/` в `.gitignore`, поэтому в свежем
клоне файла нет. Он появляется как `build/figma-variables.json` и
импортируется в Figma. Внутри четыре коллекции: `semantic` с модами
`бренд × тема` и `dimension`, `typography`, `motion` без модов.

Направление синхронизации одностороннее: JSON → Figma. Правки цветов внутри
Figma теряются при следующей сборке — это сделано намеренно.
