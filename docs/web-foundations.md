# Общие основы веба и мобильного приложения

Эта таблица актуализирует основы исходного спека от 2026-09-08. Эталон —
`aurora-web-design-system/design-system/tokens/source.json`, ревизия
`c5ed64d3abea734bbad48e738fbec196df6ce81c`, сопоставление от 2026-11-06.
Снимок выбранных значений, SHA-256 исходника и имена веб-ролей находятся в
`test/fixtures/web-foundations.json`. CI работает без соседнего репозитория.

## Цвет

Aurora соответствует веб-теме DEFAULT. МТС — самостоятельный бренд, не RED2:
его заливки и нейтральные поверхности сохранены. Статусы общие для брендов.

| Мобильная роль | Веб-роль | Light / dark Aurora |
|---|---|---|
| `action.primary` | `ds-brand` | `#2B5F9E` / `#5B92D4` |
| `action.text` | `ds-brand-text` | `#235081` / `#9DC0EA` |
| `text.primary` | `ds-fg` | `#1D222C` / `#EEF0F4` |
| `text.secondary` | `ds-fg-muted` | `#5E6676` / `#A7AEBD` |
| `surface.ground` | `ds-bg` | `#F6F7F9` / `#0D1015` |
| `surface.content` | `ds-surface` | `#FFFFFF` / `#15191F` |
| `surface.overlay` | `ds-surface-raised` | `#FFFFFF` / `#1C2129` |
| `status.moving` | `ds-state-moving` / success solid | `#157A45` / `#38B076` |
| `status.parked` | `ds-state-parked` / neutral solid | `#5E6676` / `#8C94A3` |
| `status.warning` | warning solid | `#9A6400` / `#D69E2E` |
| `status.alarm`, `status.offline` | danger solid / `ds-state-offline` | `#C1291F` / `#E76256` |

`alarm` сохраняет мобильное значение критической тревоги: это danger,
а не жёлтый веб-статус `ds-state-alarm`. Различать тревогу и потерю связи
нужно также подписью/иконкой. Карта и палитра геозон остаются мобильными.

`action.text` используют ghost-кнопки и подписи выбранных чипов;
`action.primary` — заливки и индикаторы. Для МТС в dark брендовые чернила
берутся из существующей ступени 300 (`#EE7175`), поскольку ступень 400 —
заливка, не текст на приглушённом фоне. `text.onSolid` используется на
опасной кнопке и в Material `onError`, `text.onBrand` — на primary.
`action.pressed` — смесь заливки с её чернилами на 16%, как веб-оверлей.

Адаптации поверхностей:

- `surface.chrome`: веб-фон страницы в light и поднятая поверхность в dark.
- `border.hairline`: `ds-divider` в light, более сильный `ds-border` в dark.
  Мобильные панели разделяются тоном и границей без теней; прежние пороги
  контраста сохранены.
- Полупрозрачные веб-подложки selected/subtle в dark сведены с
  `surface.content` в непрозрачный цвет. Это фиксированная мобильная
  подложка, а не универсальный веб-оверлей поверх любой поверхности.

Цветовые роли хранятся в `color.roles` бренд-файлов; ссылки — в
`tokens/semantic/color.json`. Числовые `neutral`/`brand` шкалы оставлены для
совместимости, scrim и старых ссылок. Они не являются эталоном веб-палитры;
новые интерфейсы используют семантические роли, а не ступени старых шкал.

## Типографика

Inter Tight — интерфейс; JetBrains Mono — телеметрия. Оба вариативных TTF
поставляются в Flutter-пакете. Их SHA-256 совпадают с исходниками, указанными
в веб-репозитории; происхождение и лицензии находятся рядом со шрифтами.

| Mobile | Web | Размер / высота строки | Вес |
|---|---|---|---|
| display | display | 30 / 36 | 600 |
| title | title | 20 / 24 | 600 |
| section | section | 16 / 21.6 | 600 |
| body | body | 14 / 21 | 400 |
| bodyStrong | body-strong | 14 / 21 | 500 |
| label | ui | 13 / 17.55 | 500 |
| caption | caption | 12 / 16.2 | 400 |
| overline | eyebrow | 11 / 14.85 | 600 |
| mono | mono | 13 / 17.55 | 400 |

Tracking display/title — −0.015 em, overline — 0.06 em и верхний регистр.
Числовые `numberLg/Md/Sm` сохраняют размеры 20/14/11 и табличные цифры
Inter Tight. Для координат, IMEI и временных меток используйте `mono`.
Арабский fallback сохранён; Noto Sans Arabic по-прежнему не входит в пакет.
Старый Inter оставлен в assets для совместимости, новые темы его не используют.

## Размеры и движение

Радиусы совпадают: xs=4, sm=6, md=8, lg=12, xl=16, pill=999.
Базовые отступы 2/4/8/12/16/20/24/32 совпадают с cozy-шкалой веба;
мобильные 40/48 и ноль сохранены. `touchTarget=44`, строки 40/52/64,
экранный отступ 16 и отступ строки 14 не уменьшаются до desktop compact.
Fast=120 мс и base=180 мс общие; slow=320, dataInterp=500 и кривые
easeOutCubic/easeInCubic оставлены для мобильных переходов.

## Следующее согласование

Сначала сравните исходные веб-роли со снимком, затем обновляйте локальные
токены и снимок вместе. Изменения веба автоматически не импортируются.
Выполните `mise exec -- npm run build`, `mise exec -- npm test`, затем
`mise exec -- flutter analyze` и `mise exec -- flutter test` внутри пакета.
Проверьте галерею Aurora/МТС в light/dark. Пороги контраста не понижайте.

Новые роли типографики имеют значения по умолчанию в конструкторе.
У старых пользовательских `AuroraColorTokens` новые роли `actionText` и
`textOnSolid` получают прежние actionPrimary/textOnBrand; для собственных
палитр рекомендуется явно задать обе пары и проверить контраст.
