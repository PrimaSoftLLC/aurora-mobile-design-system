# Согласование основ с веб-дизайн-системой

**Цель:** перенести актуальные основы Aurora из соседнего веб-репозитория в мобильные токены и Flutter.

**Решение:** локальный снимок выбранных веб-токенов с именами и ревизией;
сборка остаётся автономной. Семантические роли сохраняют мобильные имена.
Aurora соответствует DEFAULT; МТС не соответствует RED2 и сохраняет свою палитру.
Общие статусы, типографика и радиусы применяются к обоим брендам.

**Стек:** JSON, Node.js, Flutter; существующие генераторы Dart/CSS/Figma/preview.

**Особые проверки:** МТС не перекрашивается в RED2; текст не использует заливку
бренда; шрифты действительно входят в Flutter-пакет; статусные подложки читаемы
в обеих темах; эталон не требует соседнего checkout в CI.

**Различия платформ:** мобильные поверхности без теней требуют более сильной
разделительной линии, чем веб; chrome использует поднятую поверхность в dark.
Статус alarm сохраняет смысл критической тревоги (веб danger), warning —
предупреждения; offline переносится из веб state-offline. Карта и геозоны
сохраняют мобильную семантику. Эти решения — адаптация при реализации.

Проверено: npm build/test, Flutter analyze (без замечаний), Flutter test (134 теста),
снимки галереи light/dark. Независимое ревью: замечания к описанию шкал и
показу новых цветовых ролей в превью исправлены.
