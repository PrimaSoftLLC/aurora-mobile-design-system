# Происхождение шрифтов

Inter Tight и JetBrains Mono взяты из тех же исходников, что веб-дизайн-система
(`design-system/assets/fonts/SOURCES.md`, ревизия c5ed64d3).
Для Flutter используются исходные вариативные TTF вместо веб-WOFF2.

использует Inter Tight.
