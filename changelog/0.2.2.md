# 0.2.2

Превью показывает компоненты, а не только перечисляет их. Сами компоненты не
менялись.

- Галерея в разделе «Компоненты»: каждый блок нарисован настоящим Flutter'ом
  в четырёх комбинациях бренд × тема и вшит в превью. Это не HTML-подобие
  компонента — подобие разошлось бы с кодом на первой же правке, — а снимок
  того самого виджета, который поедет в приложение.
- Снимки делает `test/gallery_capture_test.dart`. Это **не** golden-тест:
  ничего ни с чем не сравнивается, поэтому покраснеть из-за сдвига на пиксель
  между Windows разработчика и ubuntu в CI он не может. Он только рисует и
  сохраняет.
- Тест грузит настоящий Inter из пакета. Без этого `flutter test` рисует
  текст заглушкой — пустыми квадратами, — и снимок выглядел бы как сломанный
  компонент, хотя сломано только тестовое окружение. По той же причине
  экспонат оборачивается в `Material`: без него Flutter метит текст жёлтым
  отладочным подчёркиванием.
- `npm run build` перерисовывает снимки сам и умеет звать Flutter двумя
  способами — напрямую и через mise, потому что окружения два: локально
  Flutter приходит из mise, в CI — из flutter-action, и никакого mise там
  нет. Если Flutter недоступен, сборка не падает: превью собирается без
  галереи и прямо говорит, чего не хватает. Устаревшие снимки хуже
  отсутствующих.

Превью выросло с 88 КБ до примерно 680 КБ: снимки вшиты в файл, чтобы его
по-прежнему можно было отдать дизайнеру одним куском, не собирая к нему папку
картинок.
