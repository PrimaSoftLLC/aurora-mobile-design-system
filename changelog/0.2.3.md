# 0.2.3

Починка релизной сборки. Компоненты и токены не менялись.

Релиз 0.2.2 уехал с превью на 89 КБ вместо 680: галерею компонентов рисует
Flutter, а релизная работа в CI ставила только Node. Захват честно
деградировал — сборка не упала, превью собралось без снимков, — и в релиз
попал файл, в котором нет ровно того, ради чего 0.2.2 и выпускалась.
Артефакт CI при этом был правильным: у тестовой работы Flutter есть.

- Релизная работа ставит Flutter и делает `pub get` перед `npm run build`.
- Порог на размер `preview.html` перед публикацией: меньше 300 КБ — значит
  галереи внутри нет, и релиз не выпускается. Тихая деградация, которая
  собирается и не падает, ловится только так.
- Гейт совпадения пинов теперь ждёт два вхождения `flutter-version` вместо
  одного и сверяет с `mise.toml` оба.
